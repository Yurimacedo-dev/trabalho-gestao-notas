# Sistema de Gestão de Notas de Alunos

Atividade prática da disciplina de Linguagem de Programação — curso de Engenharia de Software (Anhanguera).

## Sobre o projeto

Sistema simples em Python que permite:

- Cadastrar as notas de um aluno em uma lista
- Calcular a média das notas
- Determinar a situação do aluno (Aprovado ou Reprovado)
- Exibir um relatório final com notas, média e situação

O projeto usa estruturas condicionais, laços de repetição e funções.

## Como executar

1. Acesse o [Google Colab](https://colab.research.google.com/)
2. Crie um novo notebook
3. Cole o código do arquivo do projeto em uma célula
4. Execute e digite as notas quando solicitado

## Regra de aprovação

- Média maior ou igual a 7 → **Aprovado**
- Média menor que 7 → **Reprovado**
